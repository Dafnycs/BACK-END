# O que é o DOM

O **DOM (document object model)** é a representação do HTML em forma de **árvore do objeto**

ISSO permite que o JavaScript

    -Leia elementos da página
    -Modifique textos
    -Troque imagens
    -Reaja a cliques
    -Crie elementos novos

> O navegador transforma o HTML em objetos manupuláveis.
